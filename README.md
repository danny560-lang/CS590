# CS 590 – Database Design & Development


Course: CS-590-10568-M01, SNHU
Coursework from SNHU's graduate CS 590 course. It covers relational, document and graph databases.

| Folder | What it is |
|---|---|
| `final-project-stackoverflow-neo4j/` | **Final project.** Loads a Stack Overflow dataset (users, tags, questions, answers, comments) into Neo4j, builds the relationships between them and queries the resulting graph. |
| `module-4-postgresql/` | CRUD operations against PostgreSQL from a Jupyter notebook |
| `module-5-mongodb/` | MongoDB query (MQL) and nutrient reference data |
| `module-6-neo4j/` | Graph schema written in Cypher |
| `module-7-crud-notebooks/` | Python CRUD notebooks for both MongoDB and Neo4j |

**Tech:** Python, Jupyter, Neo4j / Cypher, MongoDB, PostgreSQL

## Running the notebooks
The notebooks read login details from a local `database.conf` file. That file is not included in this repo. Create your own with your host, database, user and password.
